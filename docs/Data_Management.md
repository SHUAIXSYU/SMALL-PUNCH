# 原始资料与正式研究数据管理

## 不可修改的原始资料区

`references_private/` 保存合作者原始交付，保持文件名、目录结构和字节内容。run_001 将未跟踪的历史 `Materials/` 安全重命名到此处；迁移前逐文件读取、SHA-256、独占读取占用探测、Git 跟踪与目标冲突检查，迁移后重新核验。之后禁止用此目录运行 Abaqus、缓存、解压、写入审计或处理结果。

Git 忽略 `/references_private/`、`/materials/` 和 `/Materials/`。忽略规则不是访问控制，也不会移除已跟踪文件；每次新增来源仍须检查 Git 跟踪情况。不得强制 add 私有资料。

原始文件清单、SHA-256、来源单元格、环境定位及私有审计保存在 `run/run_001/artifacts/private/`，该目录也被忽略。公开 README 不收录原始文件内容、数值、私有文件名或完整本地路径。审计副本不能代替备份；本 Run 未创建仓库外备份，Git clone 不包含私有区。

## 进入正式研究区的流程（规划，尚未执行）

1. 登记 source_id、提供方/授权、接收时间（不明为 UNKNOWN）、私有相对路径、原始 SHA-256。
2. 确认文件可读、数据含义、试样标识、列映射、单位、工程/真实及总/塑性定义，保留缺失字段，不猜测。
3. 经明确的版本化预处理/导入流程，生成新的工作副本或派生数据。实验数据进入 `experiments/<dataset_id>/`；模型工作副本进入 `CAE/Models/`。此目录规则不自动授予数据公开权限。
4. 保存 source_id、源哈希、处理脚本与 Git HEAD、参数、处理时间、输出哈希、删点/滤波/单位转换及质量检查。原始数据永不回写。
5. 将派生结果和元数据关联到对应 Run。合作者资料默认私有，发布前需确认授权和脱敏；未确认时给目标数据目录增加忽略规则。

未来数据契约至少明确 force、displacement 的单位、正负号、采样和零点、加载/卸载分支、设备柔度处理、重复试验标识及测量位置。图像或公式工作簿不能自动认定为实验力–位移原始记录。

## 模型和结果

CAE 原始参考副本与生成模型统一归属 CAE/Models，不把 references_private 作为工作模型目录。求解目录为 CAE/Jobs 下隔离目录；ODB、SIM、LCK 等大型/中间文件不进 Git。INP、脚本、配置是否提交须确认内容可公开；CAE 二进制只在明确版本管理方案和体积许可下考虑。

本 Run 没有正式数据导入、没有生成材料表、没有 CAE 修改或求解。当前的目录职责不代表已有可用数据集或模型。
