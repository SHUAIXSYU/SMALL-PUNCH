# Research figures

All figures in this directory are original project schematics. They contain no experimental data, copied paper images or inferred project dimensions.

| Figure | Purpose | Limits |
| --- | --- | --- |
| [spt_setup.svg](spt_setup.svg) | Axisymmetric section showing disc, spherical punch, upper clamp, lower support, imposed downward displacement and axial force measurement. Shared by both README files. | Initial contact only, not to scale; actual geometry, instrumentation, friction and boundary conditions remain unverified. |

The SVG has an explicit white background, dark English labels, internal arrow definitions and a generic system-font stack. It contains no JavaScript, remote resources, embedded raster image or external font. Edit its vector primitives and labels directly. Preserve the specimen between the clamping/supporting faces, the central opening and force/displacement directions.

Two additional diagrams are maintained as native Mermaid code in both README files: the proposed five-layer inverse architecture and the RL evaluation/reward loop. Their English labels and topology must stay identical across language versions. Policy updates in the second diagram are training-only; deployment can use a fixed policy.

Audit and rendering evidence belong to run/run_002/artifacts; those previews are not scientific simulation results.
