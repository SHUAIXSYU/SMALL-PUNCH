## 数值与实际可测性边界

- 同材料主特征粗细差最大.104986μm，远小于指定配对3.174–3.984μm，但不是R18端点误差上界；.1μm情景数值分辨有限。
- 对1μm名义界限加减这一观察尺度的**诊断**，5N D_Q约2.921–3.989MPa，10N约2.921–6.530MPa，仍收缩而成员变化；这不是主评分替换或可靠误差模型。
- 参考r=.5/1/1.5mm在I06终态移至约.605/1.213/1.630mm，实际测量必须追踪材料点。模型孔内可变形不证明真实光路可达。
- 假设每点径向定位±10μm，当前离散形状给出的主特征端点变化和可达约14.72μm；1μm的压入阶段偏差约产生.22μm特征变化。均为情景，不能当作仪器规格。
- 若每个点位移误差≤δ，差分最坏误差可达2δ；τw约束派生差分量，不能默认δ=τw或独立高斯。实际精度、同步、相关性、离面测量和光学遮挡需合作方确认。
