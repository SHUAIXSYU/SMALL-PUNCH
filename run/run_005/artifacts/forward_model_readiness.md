# 正向模型准入判断

本轮总体 **WARNING**。现有模型已具备可审计的 Punch RP Force–Displacement 提取能力，但尚不足以作为已验证的正向模型直接进入正式参数化求解与反演。

| 层级 | 判定 | 支持证据 | 尚未满足的范围 |
| --- | --- | --- | --- |
| Level 1 — Model Evidence | **WARNING** | 已定位相关文件；INP/ODB 网格、Step、RP、边界/接触链路相符；Journal 已按顺序审计 | 材料应变语义、单位、轴线约束、网格/接触充分性和保存 CAE 与 INP 的一致性未验证 |
| Level 2 — ODB Extraction | **PASS** | 同一实际 Punch RP 181 点 U2/RF2，真实 CSV/图；History/Field 一致，原始符号保留，定向换号，无插值和 2π 追加 | PASS 仅指模型单位内的读取与变换；不等于实验标定、物理有效性或统一物理单位已通过 |
| Level 3 — Forward Reproducibility | **WARNING** | 两个分开保存、不同创建时间的成功 ODB，INP SHA-256 一致；181 点 U2/RF2 和8项能量历史逐点相同 | 提供有限历史同输入重复证据；本轮没有受控重算，未验证 CAE→INP 再生成、环境/硬件独立性、参数变化或收敛性 |

Level 3 的结论不是“只发现一次成功 Job”，也不是“已完成受控重复试验”。TempTry 与 Sanity 的对比数据从各自 ODB 分别读取，没有混用任一组日志来判定另一组完成。

当前具备继续设计参数化接口所需的节点/集合与结果结构信息，但**正式参数化求解准入暂不通过**：优先澄清材料应变/单位，审查轴线约束与误导性集合名称，并处理数值敏感性。没有实验对照曲线，不能计算误差、宣称实验吻合或进行有效反演验收。

数值上：载荷/位移与能量外功核验支持提取正确；45 次失败尝试、被拒绝试算态中的负特征值/畸变，以及曲线局部陡增仍需解释。存储 ETOTAL 很小不等于所有接触能量已独立核验。实际图、统计和限制详见 [ODB 审计](odb_audit.md) 与 [Journal 审计](jnl_model_audit.md)。

下一步如需修订模型、重新生成求解输入、受控重复求解、网格/增量敏感性或参数化 Job，**需要用户新的明确授权**。本轮授权只覆盖现有文件只读审计，故此处停止；没有提交 Solver、datacheck、优化或 RL。
