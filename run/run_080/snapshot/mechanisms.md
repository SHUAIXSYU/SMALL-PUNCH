# 真实场数据支持的物理机制及其边界

本页由10个已有ODB的四阶段真实S/PEEQ/U/CPRESS与能量派生，只发布经审查纯FE汇总；无合作方实验。原始ODB、每IP私有原始提取与身份台账均留本地。全部源hash通过核验，3个新Job身份见jobs.csv；四阶段真实保存位移偏差保留在stage_metrics.csv，不按相同帧号配对。

## 已直接核实的现象

材料表提供受控干预证据：B4_01/B4_02在p=.1相对I06应力差约+3.521796/−3.207393 MPa，到p=.3变为−.100799/+.774527 MPa，并在更高p保留此偏移。硬化率变化积分后不是严格局部应力扰动。后段流动应力更接近中心，同时低段目标曲线仍不同，为响应补偿提供材料层面的解释，不能按当前PEEQ分区直接分摊RF。

细层I06在压入.3mm已有约1.515%全试样参考体积进入p≥.0982617；终态约12.25%体积PEEQ>.1、6.16%>.3、1.78%>.5，最大PEEQ约.703。位置图显示塑性演化局部集中，外侧大量试样不活跃。体积采用实际CAX4积分点2πr_ref detJ_ref权重，不用截面面积代替三维体积。PEEQ是等效塑性应变，不是真总应变。

在细层I06中心r<.5mm，近下/上表面径向S11于.3mm约+394/−116MPa，.6mm约+348/+171MPa；到末段仍均为拉应力。但外围r1.5–2mm到末态仍约−209/+371MPa。环向应力也有空间不均。此处支持局部拉伸作用增强与外围弯曲共存，**没有验证全局弯曲—膜转变点**。这些是当前Cauchy应力按参考位置分组的描述性均值，不是变形后截面内力/力矩，近表面IP也不是精确表面应力。

接触尖峰邻域：细层u≈.76995mm，B4_02有39个正压节点、I06及B4_01为40个；B4_02约.77070mm加入下一节点。1.12470mm附近也存在42/43节点错位。不同节点数与压力差可造成局部响应差，但材料变形与离散都会移动接触事件；不能把所有峰解释成纯数值误差。所有F–D尖峰保留。

全局终态ALLPD：B4_01=.6177837252616882J、B4_02=.614570140838623J、I06=.6158751845359802J。无PENER区域塑性耗散输出，区域功分解NOT_EVALUABLE；未用S:dPE替代精确有限应变耗散，塑性功比例不等于RF贡献比例。

虚拟底面形状指标w(r=.5mm)−w(r=1.5mm)，仅对已有U场按真实冲头位移括帧、参考半径线性插值。L2两个补偿材料的指标差在.3/.6/.9/1.2mm为−.133189/−.491856/−.001206/−.076789μm。同材料L2−L1最大约.09118μm；在.6mm三项分别约.01487/.02823/.02673μm。因此.6mm是有潜力的虚拟观测阶段，.9mm材料差明显较弱，终态差与已观察数值层级变化同量级。没有真实DIC误差、网格验证或独立留出，H4仍UNRESOLVED。

## 三个可证伪的竞争解释

| 解释 | 现有支持 | 可削弱/否定其作为主要解释的结果 | 缺证据和下一步 |
|---|---|---|---|
| M1 低高段硬化积分后的流动应力偏移相抵 | 表数据在较高p接近中心、真实反向F–D减弱，同向增强 | 对同族干预，高p应力不接近中心且反向响应不降低，或低/高符号对照失效 | 现有表与ODB可检验，当前结果支持；不能据此唯一分解反力因果 |
| M2 变形/应力重分布改变弯曲与拉伸共同承担方式 | 中央厚度应力符号演化、外围持续反号、虚拟底形不同 | 对齐后应力厚度结构/形状在可分辨尺度上不变，则会削弱此机制的独立贡献 | 正确当前截面几何、应力变换和实验形状证据仍缺；无全局转变点 |
| M3 接触事件时序和离散调制局部残差 | .77/1.125mm附近实际活跃节点/压力错位，tau2成员随细化翻转 | 事件时序相同而局部峰仍变化，或峰不邻近任何接触/压力变化，则削弱纯时序解释 | 已有完整历史可继续检验，无需立刻新FE；接触物理与数值离散尚不能唯一分离 |

三者可同时存在。M1有受控材料干预基础；M2/M3是有真实场数据支持的解释性机制，尚非唯一因果结论。J2各向同性模型不包含晶格/位错机制，本研究不作此类微观推断。PHYSICAL_MECHANISM=UNRESOLVED（唯一解释），H2-A响应补偿SUPPORTED、H2-B目标范围稳健扩大UNRESOLVED。外部材料正式验证仍NOT_EVALUABLE；历史信息暴露声明保持。
