# run_020 局部有限差分协议 v1

## 设计与复用范围

中心C为真实run_014，sigma_y=200 MPa、n=0.1。沿用探索边界sigma_y=[150,1000] MPa、n=[0.02,0.50]，x=ln(sigma_y/150)/ln(1000/150)，y=(n−0.02)/0.48。中心(xc,yc)=(0.15164147483749477,0.16666666666666669)，两方向h=0.05。

L01/L02分别为x−/x+，L03/L04分别为y−/y+。完整物理参数以parameter_design.json为准。sigma_y为对数对称，物理值相对中心约−9.05%/+9.95%；n为0.076/0.124，相对中心±24%。不把此域称为材料先验置信区间。没有访问保留拉伸数据；历史信息暴露仍保留。

较低Loss仅支持优先在已评估的较好区域获取局部信息，不证明中心是真值、局部极小或全局最优。旧h=.2会给出下侧sigma_y≈136.851 MPa、n=.004，超出沿用探索域。h=.05为本轮预先固定的局部分辨尺度，未按新结果、最小Loss或隐藏数据调整；不声称它是最优差分步长。

run_014仅作条件式探索性复用：原INP、35行材料表、原ODB/170点FD、几何/BC/接触/步和输出控制、生成器与固定Loss契约均需身份一致。历史39次cutback和被拒尝试负特征值/畸变警告保留，不能把它当成数值误差已知的中心。中心不重算、不生成替换INP。所有新点只替换材料表与候选注释。

## 固定读取与评分

未来每个新Job由真实ODB Agent只读提取。绑定完整INP hash、queue_id、Job/工作目录、实际命令和ODB材料数值。Datacheck/Full成功、STA完成、源稳定/无写锁、实际RP唯一、U2/RF2时间相配后，使用u=-U2、F=-RF2，单位m/N。历史名字Q200N01或Job-1不作身份依据。

沿用run017-exploratory-fd-v1：0–1.2mm固定241点，等权，F_ref=1428.9N，线性插值，不外推、不平移、不二次校正、不删点或平滑。先核验原Loss配置、目标CSV和实现哈希。所有曲线覆盖整个窗口才可评分；失败/缺失/非单调/NaN/单位未知则Loss=null并说明，不能更换某个点的窗口。L=mean(((F_FE-F_exp)/F_ref)^2)，RMSE=sqrt(L)*F_ref，NRMSE=sqrt(L)。继续标为冻结探索性比较，不能升级为实验验证结论。

## 敏感性及可识别性

所有C/L01–L04先插值到同一固定实验网格u_i。

- Sx=(F_L02−F_L01)/0.1，Sy=(F_L04−F_L03)/0.1。单位均为N/单位归一化参数。
- 原始J_N=[Sx,Sy]；同时报告每列L2范数、RMS及未去均值余弦cos(phi)=Sx·Sy/(||Sx|| ||Sy||)，角度acos(cos)。余弦不是Pearson相关。
- 报告J_N奇异值及条件数，并额外报告J_N/(F_ref*sqrt(241))的奇异值，与run017冻结RMS归一化诊断一致。整体尺度不同不改变条件数。零范数/秩亏用null和原因，不用除零产物。
- 二阶差分Cx=(F_L02+F_L01−2F_C)/h²，Cy=(F_L04+F_L03−2F_C)/h²，报告RMS及与一阶响应的尺度关系；明显曲率意味着有限割线未必代表微分极限。
- 物理导数换算：dF/dsigma_y≈Sx/(200*ln(1000/150))，单位N/MPa；dF/dn≈Sy/0.48。
- 固定描述区间[0,0.4)、[0.4,0.8)、[0.8,1.2]mm分别报告各列RMS、余弦和局部SVD。区间用于观察信息分布，不改变Loss窗口或权重；独立区间中的近共线不能由全程幅度掩盖。不得按最低Loss挑选区间。
- 条件数>100、|cos|>0.95或响应接近数值误差时提示弱可区分，沿用工程诊断门槛，不是统计检验。FE误差尚无估计，不能仅依阈值宣布辨识通过。更小h会放大数值误差；同一材料插值容差不等于同一FE误差上界。

缺失一对时仅计算存在的成对方向，不能补全J。若某方向响应完全缺失，角度、双参数SVD/条件数均不报告。五点有限差分不能证明全域唯一性、严格置信区间或最终参数真值。
