# 离线反演准备：方案 v1，尚无新 FE 授权

**历史方案保留。** 用户后续盲反演协议已冻结探索域、初始设计和预算，当前执行约束以仓库 `docs/Blind_Inversion_Protocol.md` 及本目录 `blind_inversion_contract.json` 为准；本页“边界null/先验中心”的原建议不再是当前契约。原SPT数据和Loss未改。

## 当前接口

- `inverse/fd_loss.py` 接受显式 m/N 曲线、冻结目标、固定正权重、固定力尺度和 FE 结束状态。没有 Abaqus、Queue、进程或优化器调用。
- `calculate_provisional.py` 是已有 CSV → 哈希校验 → 固定目标采样 → Loss/私有图的离线适配器。
- 正式 `FORMAL` 模式要求来源、单位/符号、测量对齐、试验条件、数值质量全部通过；否则拒绝。`PROVISIONAL` 明示所有缺口，不能授予优化权限。
- 失败 FE、非有限值、非单调/重复位移、非法单位、覆盖不足直接拒绝并保留原因，不能转成零误差。未来优化器如需失败惩罚，须预先固定策略；本版没有优化适配器或惩罚映射。
- 插值仅为 FE 到固定实验点的分段线性插值；不外推、不自动缩短目标区间、不自动改零点/符号/权重。

## 冻结目标规则

真实目标文件、区间、实验点、固定 F_ref、转换假设、源哈希及结果都在 `private/`，公开文档不包含可恢复的合作方曲线。
本轮选择窗口仅依据既有 FE 预设位移覆盖，计算残差之前冻结。以后更换候选参数不得重选窗口。
F_ref 采用完整候选实验曲线的最大载荷并固定；每个原始实验采样点权重为 1。
若将来获得不同原始数据/校正依据，另建目标版本并重新准入，禁止为降低某个模型 Loss 追溯调整。
多个独立试样未来分别保留目标和 Loss；尚未批准跨试样权重或平均。

## 参数与正向链路

- theta = (sigma_y_MPa, n)，E 暂固定 210 GPa，nu 固定 0.3。
- 复用 run_007 的 `inverse/hollomon.py::generate_hollomon_table`，真总应变解释仍为候选模型。
- sigma_y、n 的材料上下界均为 **null / 待来源确认**。生成器要求 sigma_y>0、0<n<1 只是数学定义域，不是 SA508 已验证参数范围；旧 Excel 25 组不能用作材料先验。
- run_014 仅证明一个候选的工程链路可运行，未证明网格/接触/增量充分性、实验匹配或参数可识别。
- 复用 run_014 的 AbqJobPilot Project、单任务明确 INP 哈希和工作目录、公开 enqueue、GUI Runner、真实 ODB 身份和提取链路。每次新计算必须有新授权；run_014 授权已耗尽。
- 保持模型几何/BC/接触版本可追溯。材料表上限不能默默延长；结果超过有效塑性应变覆盖则标记失效并另议。

## 固定预算建议（仅提案，批准额度仍为 0）

建议一次独立试点总上限 **48 个新的唯一 FE Job**，每 Job 最多一次尝试，失败也计数，不重试：

| 用途 | 唯一新 Job 上限 | 说明 |
| --- | ---: | --- |
| 两种算法共享初始设计 | 8 | 固定随机种子 15、共同有来源的参数边界；包含可行的先验中心 |
| BO 序贯新增 | 16 | GP + EI 方案；总计 24 个观测预算含共享 8 点 |
| DE 新一代候选 | 16 | 二维 popsize=4，种群8，maxiter=2，polish=False；总计最多24次含共享初代 |
| 局部可识别性 | 4 | 最佳点两参数中心差分；建议相对扰动5%仅是数值试探假设，须处于批准边界 |
| 数值充分性 | 2 | 网格/增量敏感性方案需单独评审和授权修改范围，不使用本轮模型变更权限 |
| 确认 | 2 | 冻结参数后的确认/保留工况，具体试样/工况先定义；没有独立数据则不能称外部验证 |
| 合计 | 48 | 超额拒绝；每项分配不能自动挪用；缓存命中不产生新 Job |

这是小预算可行性比较，不是全局最优或可识别性的保证。DE 初代与 BO 初始设计使用同一组合法点；重复 theta 只读缓存，不能重新入队。失败会减少有效样本，不能用额外计算补满。
无运行时间外推承诺：run_014 的单点耗时不是参数域最大耗时。

## 算法及可识别性准入

现有 SciPy 1.16.1 可用；本环境未检出 BoTorch/GPyTorch/scikit-optimize/Optuna/bayesian-optimization。没有安装依赖，没有开发或运行 BO/DE 求解循环。下一阶段应选定现有库可支撑的 GP 实现，先做合成函数/预算门控验证。

使用标准化残差对 log(sigma_y)、n 的灵敏度矩阵，检查列相关、奇异值比和秩；以条件数>100作为**探索性警戒值**，不是材料辨识证明。结合剖面 Loss、边界命中、重复试验分散度和厚度/摩擦/柔度敏感性。单条曲线、未知柔度与夹具约束会造成参数补偿；低 Loss 不足以证明唯一材料参数。

**进入真实 BO/DE 前**必须解决：真实测量来源、载荷单位冲突、传感器/零点/柔度、实际与模型条件对应、材料边界依据、数值充分性与警告处置、固定目标版本和失败策略，以及新的总预算/逐 Job 执行授权。
