# BO/DE 单种子先导协议（run_040）

## 固定输入和成本

- 初始评价是 `artifacts/private/initial_dataset.json` 中19个可评分点；D07、D09、D10作为已知不可评分位置保留 `Loss=null`，不得改为零或人为大值。
- 两分支共同使用 `run030-standard-m0025-hollomon-v1`、`run017-exploratory-fd-v1`、σy 150–1000 MPa、n 0.02–0.50。初始22个唯一参数点已有24次已观察求解尝试；可归属的22次完成计算累计5203秒。这个历史成本对两分支共同计一次，不在比较表中分别“免费”或重复计算。
- 第一关新增高保真尝试各4次，合计8次；失败、Datacheck失败、终态不明和数值不评分均消耗一次尝试。无自动重试或替补候选。本Run新增授权为零。

## 可复现候选

- 代码 `pilot.py` 与清单 SHA-256 相互绑定。BO用归一化二维输入、`log1p(Loss)`、带有界超参数的 ARD Matérn-5/2 GP及 EI（ξ=0.005）。从固定随机种子生成的2^14个 Sobol 位置选点；每选一位置，用预测均值作虚拟观测以构成4点批量 Kriging believer。**这4点不依赖实际新FE结果，不能称为四步序贯BO。** GP预测可低于零的变换后目标，属于代理预测而非物理Loss；不得作为真实评价。
- DE用 `rand/1/bin`、8个体、F=0.7、CR=0.9、固定种子。初始种群从共享19点中以最低Loss加最远点优先规则选8个，19点全部留作共同可见历史。首批4个trial仅对应前4个target，属于**半代评估**；未取得FE结果前不做亲本替换，不声称完成一代或收敛。
- 两分支候选按已评价点0.035、已知不评分点0.04、同批候选0.07的归一化欧氏距离门槛去重。先形成BO批，再对DE trial使用已冻结BO位置做跨分支去重；仅使用位置、不使用BO未来结果。该顺序对DE提议空间有影响，比较必须披露，若严格对称对照则下一版应预先随机确定优先权并多种子重复。

## 每次未来求解的数值门控

1. INP、Job、Project、queue_id、输出和实际尝试必须绑定；Datacheck及Full均应有可信成功终态，不能因ODB存在而认定通过。
2. Punch RP U2/RF2按既有符号转换到N–m，固定实验0–1.2 mm的241点完全覆盖；不得平移零点、平滑、裁窗、外推或按候选改权重。
3. 最大保存帧PEEQ不得超过对应材料表覆盖范围；未保存或被拒绝试算的状态不能由此推断安全。审查cutback、接触演化、接受态大应变、单元畸变及接受帧局部力突跳。严重未解释问题则Loss=null。
4. 任一作业身份不明、求解失败、窗口不完整、材料表超限或系统性数值阻塞，暂停后续入队，MAIN进行独立审核；警告本身不自动等于物理失效。失败照算预算，不自动重试。

## 第一关之后

- 先完成4 BO和4 DE的实际证据审计，再决定是否申请第二关各4次。BO第二关可以依据自身第一关的有效结果做真正序贯或新批量提议；DE可只依据自身第一关的有效结果按明确的部分代更新规则形成后4个trial。两个分支不得读取对方新增结果改变候选。
- 同一新增评价次数下比较best-so-far Loss、有效FE数、总尝试数及失败率、实际wall-clock、数值质量、参数分布与低Loss等效解。明确报告共享初始成本和两分支新增成本；缓存或重复点必须记录而不能冒充新FE。
- 单种子、每支最多8次新增FE只能用于机制演练和先导探索，不能给出统计显著的BO/DE优劣结论，也不能证明参数唯一性、正式实验拟合或网格收敛。

## 参数识别与边界

D01在σy下边界150 MPa之上仅约2.309 MPa，I08的σy高约112.702 MPa、n低约0.07626而Loss接近；两条FE曲线在冻结网格上的相互RMSE仍约57.71 N。5个低Loss点的归一化坐标相关系数−0.940是选择后的描述统计，不能证明连续补偿谷地或参数非唯一。保持原边界。若未来拟扩展下界，必须先取得独立物理依据，建立新搜索域、重新处理算法比较和额外FE预算授权。
