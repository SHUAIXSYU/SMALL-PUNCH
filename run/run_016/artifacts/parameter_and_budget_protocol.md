## 来源与参数含义

1. [英国核监管机构 ONR/HSE 原始结构完整性评审，Annex 2 Table 3，PDF 第 115 页](https://www.onr.org.uk/media/documents/gda/reports/step3-uk-epr-structural-integrity-assessment.pdf)：其列出的 SA508 Grade 3 Class 1 室温规范最低屈服强度为 345 MPa，抗拉强度为 550–725 MPa。这是指定牌号/等级的公开规范比较，不是本试样测量。
2. [韩国原子能研究院 KAERI 原始研究资料，2012-11-23，Table 1](https://mdportal.kaeri.re.kr/posts/d20120060/)：其自身 Gr.3 与 Gr.4N 材料室温屈服结果分别为 459 与 581 MPa。该来源说明牌号与处理状态影响性能；不证明本批材料的状态和参数。
3. 项目 `inverse/hollomon.py` 定义真总应变候选律：弹性段 E·ε，塑性分支 σ=σ_y(ε_total/(σ_y/E))^n，再扣除 σ/E 得到塑性应变。数学条件为 σ_y>0、0<n<1；本模型 σ_y 是分段连接参数，不能直接等同于标准 Rp0.2；也不能把文献塑性应变 Hollomon 指数直接移植。

**建议下一版探索域：σ_y ∈ [150,1000] MPa，n ∈ [0.02,0.50]。**

- σ_y 下界：公开 345 MPa 尺度的一半约为 172.5 MPa，再向外取整至 150；上界：公开 581 MPa 尺度的 1.5 倍约为 871.5 MPa，再向外取整至 1000。倍数和取整是预先声明的宽松工程假设，用于容纳等级、状态及参数定义差异，**不是标准规定或统计置信区间**。
- n 的 0.02–0.50 是本候选律的工程探索假设，满足正硬化及递减切线约束，并避开 n→0、n→1 的极端。没有从本项目实验确定 n 的先验概率，也没有从上述公开强度数据反推出 n。
- E=210 GPa、ν=0.3 保持为暂定模型常量。此次合作方声明没有实验确认 E；未使用隐藏拉伸资料。默认适用条件为室温、准静态、未辐照钢材；试验温度、等级/状态仍需确认。条件不符时应在计算前版本化修改域，不能在最优值贴边后静默扩边。
- run_014 的 (200 MPa,0.1) 不作为真实值、先验中心或强制初值。既有 21–2100 MPa、0.01–0.99 仅有数学探索意义，本版收窄依据完全列于上文。

## 初始化、算法与停止规则

- 共用以上 8 点有效结果；参数空间在 [0,1]^2。所有算法随机数种子 16。初始点若失败，停止并审查，不补入未授权样本。
- DE 规划使用当前环境 SciPy 1.16.1 的 `best1bin`；显式 8 个体初始矩阵、F=0.7、CR=0.8、`maxiter=2`、`polish=False`、`workers=1`、`updating='deferred'`、`rng=16`、`tol=0`、`atol=0`。硬预算独立于库停止条件；缓存初始 8 点，不重新求解。参考 [该版本官方文档](https://docs.scipy.org/doc/scipy-1.16.1/reference/generated/scipy.optimize.differential_evolution.html)。本轮没有调用 DE。
- BO 规划：同一 8 点初始化，固定标准化输入；标准化有效 Loss 的零均值 Matérn-5/2 ARD GP，长度尺度限制 [0.05,2]、核幅度 [0.01,100]、数值 nugget=1e-6（不能解释成实验噪声）。以 EI（ξ=0.01，标准化目标单位）选择下点，固定 128×128 网格及种子 16 的 1024 个均匀候选点，排除与既有点最大坐标差小于 1e-6 的重复点；并列取字典序。超参数以固定初值 0.5,0.5,1 加 4 个同种子重启估计。该实现尚未编码/验收；需要另做不含 FE 的合成验证，不新增依赖。本轮没有拟合 GP。
- BO 每 4 个新点评审；最多 16 个。连续 8 次有效新评价的最佳 L 改善小于 max(1e-4, 0.01×该段开始的最佳 L) 时停止。DE 两代硬停；不以这么少代数宣称全局收敛。
- 任一算法遇到单位/目标身份改变、越界、数值无效、授权/预算不足即暂停；未知失败不能当零 Loss。有效性分类与原始错误日志独立于目标值保存，失败返回不可评分状态（搜索排名可视作 +∞，不向 GP 填造巨大有限 Loss）。首个失败或新的重大数值警告先人工审核，再决定是否申请新授权，自动重试为 0。
- 同参数重复请求使用精确输入/模型/目标/求解配置哈希缓存，记录 cache-hit，不新增 Job，不冒充新证据。确认复现计算须显式绕过缓存并消耗已授权次数。

## 成本与可识别性

- 一个 queue_id 的 Datacheck+Full 计一个尝试；Datacheck 失败也计一次。另记录两阶段启动数、失败数、总墙钟秒、排队/人工等待秒、CPU/GPU 分配。CPUh=Σ实际阶段墙钟秒×分配 CPU/3600，是分配核时，不是真实忙碌核时。计算失败、质量复核、确认计算都计费。
- 历史 run_014 为 165 秒/14 CPU；线性外推仅为参考：5 个约 13.75 分钟、约 3.21 分配核时，48 个约 132 分钟。模型/参数变化可能显著改变成本。首批可另申请总 60 分钟墙钟预算；达到预算/未知超时停止放行后续任务，由 Runner 和人工处理当前作业，不能擅自杀进程或重试。
- 先导及最优附近分别构造归一化 F–D 响应关于 x,y 的有限差分 Jacobian，做 SVD，报告奇异值、条件数、列相关系数和数值扰动尺度。条件数>100、|列相关|>0.95、边界最优或响应小于数值差异均标为弱可识别（预定工程诊断阈值）。不能只报告单个最优点。
- 2 个数值质量 Job 预设检查：固定网格点上的归一化曲线差异 RMS ≤1%，且不出现未解释接触/畸变/能量异常；1% 是规划阈值，尚未验证为实验噪声水平。不通过则冻结参数结论，重新申请模型研究。
- 现仅一条 SPT 曲线，未知测量噪声/重复性。报告近优域、Jacobian 条件性和模型/参数敏感性；不能把 GP 方差或任意阈值区域冒充 95% 参数置信区间。严格统计不确定性需独立噪声/重复数据及另行预算。
